## Sobre o Projeto

Este é o site institucional da Clínica Veterinária Barley Pets, desenvolvido com as seguintes tecnologias:

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router DOM

## Características do Projeto

- Design moderno e responsivo
- Animações suaves e interativas
- Performance otimizada
- SEO-friendly
- Integração com WhatsApp
- Páginas de detalhes dinâmicas para serviços e equipe

## Estrutura

O projeto segue uma arquitetura modular e componentizada, facilitando manutenção e escalabilidade.
