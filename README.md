# Barley Pets - Site Institucional

Site institucional da Clínica Veterinária Barley Pets, desenvolvido com React, TypeScript e Tailwind CSS.

## Desenvolvido por

**Lucas Kikuthi**

## Tecnologias Utilizadas

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn-ui
- React Router
- Framer Motion



## Estrutura do Projeto

```
src/
├── assets/          # Imagens, logos e recursos estáticos
├── components/      # Componentes React reutilizáveis
├── hooks/          # Custom hooks
├── pages/          # Páginas da aplicação
├── lib/            # Utilitários e helpers
└── index.css       # Estilos globais
```

## Funcionalidades

- Design responsivo e moderno
- Animações suaves com Framer Motion
- Navegação entre seções e páginas
- Integração com WhatsApp
- Carregamento otimizado de imagens
- SEO-friendly
